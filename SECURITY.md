# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting
on this repository ("Security" tab, "Report a vulnerability") and include:

- the affected version or commit,
- a minimal reproduction,
- the impact you observed.

You can expect an acknowledgement within a few days. This project runs locally,
collects no telemetry, and requires no credentials; reports about its local HTTP
server, archive handling, or path handling are especially relevant.

## Scope

The tool is not safety-critical. Do not use it as the only basis for road
maintenance or traffic-safety decisions.
